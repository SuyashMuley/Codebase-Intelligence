# Frontend

Next.js (App Router), TypeScript, Tailwind, TanStack Query. The browser only talks to this
origin: `/api/*` is proxied to the backend (see `next.config.ts`), which keeps the session
cookie first-party.

```bash
npm install
npm run dev        # http://localhost:3000, expects the API on http://localhost:8000
npm run lint && npm run typecheck && npm test && npm run build
```

Set `BACKEND_URL` (in `frontend/.env.local`) if the API is not on `http://localhost:8000`.
It is read at build time for the proxy rewrite.

Note: this project uses a recent Next.js with Cache Components enabled. Hooks that read the URL
(`useSearchParams`, `useParams`) must be inside a `<Suspense>` boundary; the build fails
otherwise. `AGENTS.md` is generated by Next and points at the version-matched docs in
`node_modules/next/dist/docs/`.
